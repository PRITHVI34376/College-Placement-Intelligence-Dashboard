# College Placement Intelligence Dashboard

## 📊 Project Overview
Interactive Power BI dashboard for analyzing BVCOE 2026
college placement data.

## 🛠️ Tools Used
- Power BI
- Power Query
- DAX
- Excel

## 📌 Dashboard Features
- Total Students
- Average CGPA
- Average Package
- Median Package
- Highest Package
- Placement Status
- Average Package by Branch
- Placement by City
- Placement by Branch
- Company-wise Package Analysis
- Branch Slicer
